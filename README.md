# 阴阳师资源流水

适用于 Windows 和 MuMu 模拟器的本地桌面工具。点击一次「记录」，工具就读取一次庭院余额。它按资源分别比较上一次保存的余额，只为有变化的资源新增流水。

## 安装和启动

1. 从仓库下载并解压源码，安装 64 位 Python 3.12，保留 Python Launcher 和 Tcl/Tk。
2. 在 MuMu 启动《阴阳师》，让游戏以 **1280 × 720** 横屏分辨率运行，并确保 ADB 能连接模拟器。默认设备序列号为 `emulator-5554`。
3. 双击 `setup.cmd` 安装依赖。安装期间需要联网下载 Python 包。
4. 回到游戏庭院，关闭弹窗，确认顶部三个资源数字和底部菜单都可见，然后双击 `calibrate.cmd`。校准只在本机保存必要的小块图像。庭院主题或界面布局变动后，可以重新校准。
5. 双击 `start.cmd`。回到游戏庭院，点流水窗口的「记录」，等待读取结束。读取期间请先不要操作鼠标、键盘或游戏。

## 记录和数据

- 某项资源还没有上次余额时，第一次成功读取会保存基准。之后即使重启工具，也会从本地恢复该资源的上次余额。
- 例如，体力从 100 变成 94，勾玉余额不变，此次只新增一条 **体力 −6**。两次读取之间的多笔收支合并为净变化。工具不会定时采样。
- 金币若只有「万」或「亿」的缩写，工具只显示该读数。勾玉和体力可从详情弹窗获取完整数字。
- 点击「打开数据文件夹」可查看 `data/ledger.csv`。基准及校准图像也保存在 `data/`。仓库没有预置这些数据。

## ADB 设置

程序先尝试查找 PATH 中的 `adb.exe`，找不到时尝试系统盘的 `MuMuPlayer\nx_main\adb.exe`。安装位置不同或有多开实例时，可在 PowerShell 里指定 ADB 路径和设备序列号。以下是示例路径，按本机安装情况替换：

```powershell
$env:ONMYOJI_ADB = 'C:\MuMuPlayer\nx_main\adb.exe'
& $env:ONMYOJI_ADB devices -l
$env:ONMYOJI_SERIAL = 'emulator-5554'
.\calibrate.cmd
.\start.cmd
```

如果提示返回庭院，确认选中了正确的模拟器实例、游戏没有弹窗，且分辨率为 1280 × 720。更换游戏账号时请使用另一份解压目录，以免把两个账号的余额放进同一份流水。
